# memyr-labs

Memyr Labs company site — served at [memyr.com](https://memyr.com).

- `index.html` is the live page: the "Two Doors" one-pager (Gift8 + notanATS), exported from the `memyr-labs-two-doors` web artifact.
- To update the site: edit the artifact, re-export, and replace `index.html` here. Vercel redeploys automatically on push to `main`.
